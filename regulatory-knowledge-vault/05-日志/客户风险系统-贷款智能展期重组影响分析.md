# 客户风险系统·贷款智能展期重组 报送影响分析

> 分析日期：2026-05-28
> 业务场景：贷款智能展期重组（逾期贷款→自动生成新借据→旧借据关闭→重算还款计划）
> 涉及客户类型：个人客户（含个经/住房贷款）和对公/单位客户
> 涉 及：五级分类变化（展期重组贷款通常不低于次级类）、授信变化、担保关系变化

### 3.2 复检发现

- **客户风险系统6张报表中无一张直接出现"展期"或"重组"字样**。这与其他系统（如1104 G11_I有"重组贷款"行、S67有"展期余额"列）形成鲜明对比——客户风险系统通过**借据号变更、五级分类变化、担保关系更新**等字段间接反映展期重组业务。
- **关键发现**：客户风险系统对贷款展期重组的影响路径是"字段级"而非"报表行项目级"——即没有专门的重组贷款行或展期贷款列，而是通过底层字段变化来反映业务。
- **对公及同业客户授信表PART III的22个字段中，约10个字段直接受展期重组影响**（如下详述）。

## 四、影响矩阵

### 4.1 必读报表影响详情

#### （1）对公及同业客户授信和表内外业务统计表 — ⭐核心命中

| 维度 | 内容 |
|------|------|
| **客户要素命中** | 对公客户（含集团客户和单一法人客户） |
| **授信要素命中** | 是 — PART I授信情况 |
| **担保要素命中** | 是 — PART III担保方式字段 |
| **违约要素命中** | 是 — PART III欠本欠息、违约准备字段 |

**冲击字段分区：**

**PART I - 授信情况：**
| 冲击字段 | 变化方向 | 说明 |
|----------|----------|------|
| 现有业务余额占用授信额度 | 可能变化 | 新借据产生后，占用授信额度的贷款余额部分不变（业务实质同一笔），但系统需确认新借据是否重新占用授信 |
| 其中：贷款余额占用贷款授信额度 | 不变 | 贷款余额不变，占用额度不变 |
| 尚可使用授信额度 | 可能变化 | 若展期重组导致额度冻结或重新核算，可用额度可能变化 |
| 关联方授信标识 | 不变 | 不影响关联方识别 |

**PART III - 贷款明细：** ⭐核心冲击区

| 冲击字段 | 变化方向 | 说明 | 依据来源 |
|----------|----------|------|----------|
| **借据号** | ⭐**新增字段值** | 旧借据关闭→新借据生成，借据号必须变更为新号码 | 原文PART III第1字段：'借据号' |
| 发放日期 | **变化** | 新借据产生新的发放日期（重组完成日/新借据生效日） | 原文PART III |
| 到期日期 | **变化** | 展期后到期日期后延（原始期限延长） | 原文PART III |
| 发放金额 | **不变** | 新借据发放金额=旧借据贷款余额（或旧借据余额） | 业务逻辑 |
| **贷款余额** | **不变** | 同一笔贷款重组，余额不变 | 业务逻辑 |
| **五级分类** | ⭐**变化** | 展期重组贷款通常不低于次级类→应从原分类（可能是正常/关注/不良）变为次级类或更差 | 原文PART III；业务事实 |
| 贷款业务种类 | **可能变化** | 若展期重组后业务性质重新认定（如品种码值变化），需更新 | 原文PART III |
| **担保方式** | **可能变化** | 若展期重组涉及担保关系变更（追加担保/解除担保/重估抵质押率），需更新 | 原文PART III |
| **欠本余额** | **归零或保留** | ⭐关键判断：新借据是否承接旧借据的欠本金额？业务上旧借据关闭时欠本清零，新借据按重组后本金重新计算 | 原文PART III |
| **欠本天数** | **重置** | 新借据的欠本天数从新还款计划首次违约日开始重新计算 | 原文PART III |
| **欠息余额** | **归零或处理** | 欠息通常在重组时处理（挂账/转本金/豁免） | 原文PART III |
| **欠息天数** | **重置** | 同欠本天数 | 原文PART III |
| **还本方式** | ⭐**变化** | 重算还款计划→还本方式可能变化（如等额本金/等额本息/一次性还本） | 原文PART III |
| **还息方式** | ⭐**变化** | 新还款计划的重算影响还息方式 | 原文PART III |
| **下期还本日期** | ⭐**新增** | 新借据有新的第一期还本日期 | 原文PART III |
| **下期还本金额** | ⭐**新增** | 新还款计划确定的新还本金额 | 原文PART III |
| **下期还息日期** | ⭐**新增** | 新还款计划确定的首次还息日期 | 原文PART III |
| **下期还息金额** | ⭐**新增** | 新还款计划确定的首次还息金额 | 原文PART III |
| 贷款发放类型 | **可能变化** | 新借据的发放类型（如新发放/借新还旧等）需要根据行内规则设定 | 原文PART III |
| **违约准备** | ⭐**变化** | 五级分类从原来变为次级类→违约准备计提比例和金额变化 | 原文PART III |
| 银团贷款标识 | 不变 | 不涉及银团结构的变更 | 原文PART III |
| 支付方式 | **可能变化** | 新借据的支付方式（自主支付/受托支付）可能与原借据不同 | 原文PART III |

#### （2）对公客户担保情况统计表 — ⭐命中

| 维度 | 内容 |
|------|------|
| **客户要素命中** | 对公客户（含集团和单一法人） |
| **授信要素命中** | 间接（通过业务合同号关联） |
| **担保要素命中** | ⭐核心命中 — 担保关系变化 |
| **违约要素命中** | 否（本表不区分违约状态） |

| 冲击字段 | 变化方向 | 说明 | 依据来源 |
|----------|----------|------|----------|
| **贷款或表外业务合同号** | ⭐**变化** | 旧借据号→新借据号，业务合同号（借据号）变更，担保关系表中业务合同号必须更新 | 报表实体页：'贷款或表外业务合同号'字段 |
| **担保关系重新确认** | ⭐**新增/变化** | 旧借据关闭后，原担保关系是否自动延续到新借据？是否需要重新签订担保合同？如果是自动延续，需在系统中更新业务合同号关联；如果需要重新确认，则新增担保关系记录 | 报表实体页：'业务合同-担保合同-押品/保证人'关系逐行填报 |
| 押品名称/押品代码 | 不变（除非押品置换） | 展期重组本身不改变押品 | 报表实体页 |
| 押品权属人信息 | 不变 | 权属人不变 | 报表实体页 |
| 押品最新估值日期 | **可能变化** | 重组时可能重新评估押品价值→估值日期更新 | 报表实体页 |
| 押品估值到期日期 | **可能变化** | 估值更新后到期日期重新计算 | 报表实体页 |
| **押品抵质押率** | ⭐**可能变化** | 若押品重估或贷款余额变化→抵质押率变化；若贷款余额不变、押品估值不变→抵质押率不变 | 报表实体页 |
| 保证人保证能力上限 | **可能不变** | 保证人财务状况不因展期重组而自动变化 | 报表实体页 |
| 担保合同类型 | **可能变化** | 若涉及担保方式变更（如从保证变抵押） | 报表实体页 |

#### （3）个人贷款违约情况统计表 — ⭐⭐核心命中（含关键判断点）

| 维度 | 内容 |
|------|------|
| **客户要素命中** | ⭐个人客户（含个经/住房贷款） |
| **授信要素命中** | 否（本表不涉及授信额度） |
| **担保要素命中** | 含担保方式字段 |
| **违约要素命中** | ⭐核心——逾期90天以上违约 |

| 冲击字段 | 变化方向 | 说明 | 依据来源 |
|----------|----------|------|----------|
| **借据号** | ⭐**新增** | 新借据生成，借据号变更 | 报表实体页原文定位 |
| 贷款品种 | **不变** | 贷款品种不因展期重组变化（仍为住房公积金贷款/其他农户贷款等） | 报表实体页 |
| 担保方式 | **可能变化** | 同对公担保分析 | 报表实体页 |
| 发放金额 | **不变** | 新借据发放金额=旧借据结欠余额 | 业务逻辑 |
| 结欠余额 | **不变** | 余额不变 | 业务逻辑 |
| 发放日期 | **变化** | 新借据发放日期 | 报表实体页 |
| 到期日期 | **变化** | 展期后到期日期后延 | 报表实体页 |
| **违约天数** | **⛔可能出现但需判断** | ⭐**关键判断点**：新借据生成后，违约天数应从新借据的约定还款日起算。展期重组后新借据有新的还款计划，理论上新借据最初不应处于违约状态→违约天数为0或不存在。但是：| 报表实体页：'违约天数从约定还本或还息日期的次日开始连续计算' |
| | | ①若展期重组前已连续逾期90天以上，在展期重组**发生前**的报送时点，该笔贷款已应进入本表 | |
| | | ②展期重组后，新借据有了新的还款计划，除非新还款计划立即违约，否则**本表不应再包含该笔贷款** | |
| **五级分类** | ⭐**变化** | 展期重组贷款不低于次级类→五级分类从原状态变为次级类或更差；但本表统计的是逾期90天以上，若新借据不再逾期，即使五级分类为次级也未必在本表（本表口径：连续逾期90天以上） | 报表实体页 |
| **最近一次还款金额** | **重置** | 新借据后最近一次还款为首次还款 | 报表实体页 |
| **最近一次还款日期** | **重置** | 同上 | 报表实体页 |
| **共同债务人信息** | 不变 | 共同债务人信息不因展期重组变化 | 报表实体页 |

⚠️ **关键陷阱判断**：本表与对公表存在根本差异——本表是"事件触发型"报表（条件：连续逾期90天以上），而非"存量统计型"。展期重组实际上可能**终止**该笔贷款在本表的报送条件（新借据新还款计划→不再逾期）。因此**展期重组对个人贷款违约统计表的实质影响是"该贷款退出违约统计"**，而非新增违约数据。

但如果展期重组后借款人仍然无法按新还款计划还款，再次逾期90天以上，则将再次进入本表（以新借据的新违约天数计算）。

⚠️ **联动判断**：本表与个人贷款违约情况统计表是联动关系。如果展期重组导致个人贷款退出违约统计（即新借据不再逾期90天以上），则本表的数据也随之清除或不再报送。反之，如果展期重组后贷款仍处于违约状态，则需更新本表的贷款合同号等信息。

## 五、已有结论、推断判断、待确认事实

### 5.1 已有结论（可确认）

1. **对公及同业客户授信和表内外业务统计表 - PART III为最大冲击区**：22个贷款明细字段中约10个直接因展期重组变化（借据号、发放日期、到期日期、五级分类、欠本欠息、还本还息方式、下期还本还息日期/金额、违约准备）。

2. **五级分类字段必变化**：展期重组贷款不低于次级类，对公表PART III的"五级分类"字段必须从原状态更新为次级类或更差。

3. **个人贷款违约情况统计表的报送影响是"退出型"而非"新增型"**：展期重组后新借据新还款计划，除非立即违约，否则该笔贷款不再满足"连续逾期90天以上"的报送条件。因此该表的数据会**减少**一笔记录。

4. **个人违约贷款担保情况统计表联动退出**：因联动个人贷款违约统计表，如果前者退出，后者也随之退出（或至少不再有该笔贷款的担保关系报送义务）。

5. **客户风险系统整体无"重组贷款"或"展期贷款"的专项行项目**：这与1104系统（G11_I有重组贷款行[5]、展期贷款行[6]）和一表通（6.7贷款展期协议）形成显著差异。客户风险系统通过字段级变化反映展期重组业务。

6. **对公客户担保情况统计表中业务合同号必须更新**：旧借据号→新借据号，否则担保关系无法正确关联到新借据。

### 5.2 推断判断（需验证）

1. **欠本欠息字段的处理方式**：推断——展期重组时欠息通常被处理（可能转本金、挂账或豁免），新借据的欠本余额=旧借据的贷款余额（不含欠息），欠息余额清零。但具体处理方式取决于行内会计政策，需要确认。

2. **违约准备的重新计算**：推断——五级分类变为次级类后，违约准备（即拨备）计提比例从原比例（如正常类1%、关注类2%）变为次级类（通常25%）→违约准备金额大幅增加。

3. **担保关系的自动延续 vs 重新确认**：推断——从"线上自动化流程"的业务模式看，担保关系很可能自动延续到新借据（无需重新签订担保合同），因此对公担保表中的业务合同号更新即可；但如果涉及押品重估或保证人保证能力重审，则需同步更新押品估值和抵质押率。

4. **个人贷款品种不因展期重组变化**：推断——住房公积金贷款展期重组后仍为住房公积金贷款，其他农户贷款展期重组后仍为其他农户贷款，贷款品种码值不变。

5. **个人客户中个经/住房贷款的报送归属**：推断——个人经营性贷款和住房贷款均属于个人贷款范畴，只要满足"连续逾期90天以上"条件，均应进入个人贷款违约情况统计表。展期重组后该条件消失→退出该表。
