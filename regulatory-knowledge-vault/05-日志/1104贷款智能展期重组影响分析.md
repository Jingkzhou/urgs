### 3.2 复检发现

- **新增候选**：G09（互联网贷款业务情况表）——因业务模式为"线上自动化流程"，需判断是否属于互联网贷款。G09定义要求"线上自动受理、风险评估、授信审批、合同签订、贷款支付、贷后管理全流程线上化"，智能展期重组自动生成新借据并重算还款计划可能符合此定义。
- **排除确认**：G13（押品情况统计表）——展期重组不改变押品，除非发生押品置换；展期重组本身不触发G13数据变化，排除。

## 四、影响矩阵

### 4.1 必读报表影响详情

#### （1）G01 资产负债项目统计表 — 命中

| 维度 | 内容 |
|------|------|
| **冲击类型** | 变化（存量贷款形态变化，非新增） |
| **冲击字段** | 各项贷款[62]总量不变（旧借据关闭+新借据产生，余额不变）；不良贷款[63]可能变化（展期重组通常不低于次级类→可能从不良好转为不良或从关注转为不良） |
| **依据来源** | G01实体页：各项贷款统计口径为贷款、贸易融资等全量 |
| **说明** | 新借据生成、旧借据关闭对G01各项贷款总量无影响（同一客户同一授信下的同一笔贷款重组，余额不变）。但五级分类变化会影响不良贷款子项的分布。G01[24]各项资产减值损失准备与G03表间校验。 |

#### （2）G01_III 存贷款明细报表（一）— 命中

| 维度 | 内容 |
|------|------|
| **冲击类型** | 变化 |
| **冲击字段** | 短期贷款[1.1] / 中长期贷款[1.2]分类可能变化（若展期后延长至1年以上） |
| **依据来源** | G01_III实体页：短期贷款=原始期限一年以下（含一年），中长期=原始期限一年以上 |
| **说明** | 若展期重组将原短期贷款延长至1年以上，则该笔贷款从[1.1]短期迁移至[1.2]中长期。需按展期后新借据的原始期限重新归类。个人经营性贷款在此表不进[2.21]个人贷款分类，而是作为"各项贷款"总量的一部分。 |

#### （3）G01_II 贷款质量五级分类情况简表 — 命中

| 维度 | 内容 |
|------|------|
| **冲击类型** | 变化 |
| **冲击字段** | 正常类[1.1.1]、关注类[1.1.2]、次级类[1.2.1]、可疑类[1.2.2]、损失类[1.2.3] |
| **依据来源** | G01_II实体页：贷款逾期展期规则"借新还旧和展期贷款的逾期天数从原借款合同到期日起算" |
| **说明** | 展期重组前为逾期贷款，按G11_I规则重组贷款原则上不低于次级类。因此五级分类必然发生变化，G01_II中正常贷款→不良贷款的迁移将在此表体现。展期后逾期天数计算规则：借新还旧展期从原合同到期日起算，正常展期从展期后到期日起算。 |

| 维度 | 内容 |
|------|------|

| **冲击字段** | **[5]重组贷款**、**[6]展期贷款**、**[4]逾期贷款**、**[7]个人经营性贷款（附注）** |

#### （6）G12 贷款质量迁徙情况表 — ⭐⭐⭐核心命中（含陷阱判断）

| 维度 | 内容 |
|------|------|
| **冲击类型** | 变化+特殊处理 |
| **冲击字段** | [A]年初余额、[B]本期减少、[2]本期增加、[3]-[7]迁徙分布、[J]重组调整 |
| **依据来源** | G12实体页：迁徙统计原则"仅反映年初和期末两个时点"；重组贷款定义；重组调整[J] vs 非重组调整[K] |
| **关键陷阱判断** | |
| | **G12实体页原文**：G12"以单笔贷款为单位进行统计"，"反映同一笔贷款年初五级分类结果和期末五级分类结果" |
| | **业务冲击**：旧借据关闭→新借据产生，技术上是两笔不同借据（不同借据ID） |
| | **结论**：G12迁徙路径**中断**。旧借据在报告期末已不存在（"本期减少"[B]列），新借据作为"本期增加"[2]列体现。这意味着该笔贷款的迁徙路径无法从年初持续追踪到期末。在G12中： |
| | - 旧借据进入[B]本期减少（因被新借据替换） |
| | - 新借据进入[2]本期增加（作为新发放贷款） |
| | - **年初正常→期末不良的迁徙轨迹丢失**，G12无法反映该笔贷款的真实质量恶化过程 |
| | - 第二部分[J]重组调整列可能涉及：若旧借据年初为不良，新借据因重组转为不良，则[J]列记录重组调整金额 |
| **说明** | 这是本业务最大的监管报送陷阱。银行需确认：是否将智能展期重组视为"同一笔贷款的合同调整"（G12继续追踪）还是"旧贷结清+新贷发放"（G12迁徙中断）。从业务事实看，旧借据关闭+新借据产生的模式更接近后者，即迁徙路径中断。建议与监管确认该业务模式在G12中的处理方式。 |

## 五、已有结论、推断判断、待确认事实

### 5.1 已有结论（可确认）

1. **G12迁徙路径中断**：旧借据关闭+新借据产生模式导致G12"同一笔贷款"的迁徙追踪中断。旧借据进"本期减少"[B]，新借据进"本期增加"[2]。这是本业务最大的监管报送陷阱，需与监管确认处理方式。

2. **G11_I[5]重组贷款必命中**：展期重组符合G11_I重组贷款定义（债务人财务困难+合同调整），且重组贷款原则上不低于次级类。

3. **G05排除个人经营性贷款**：G05仅含个人非经营性贷款，若本业务涉及个人经营性贷款，应进入S63_III[G]列，不进G05。

4. **G04双重冲击**：利率调低→利息收入减少；五级分类恶化→拨备增加→资产减值损失增加。两者均压低利润。

5. **G03拨备计提增加**：五级分类恶化导致贷款损失准备计提增加。

6. **S63排除无还本续贷**：S63[6.3]"无还本续贷"明确排除"贷款到期后的重组、贷款展期等情况"。

7. **G01总量不变**：旧借据关闭+新借据产生不改变各项贷款总量（余额不变）。

8. **S67展期列 vs 重组列**：S67有展期余额[I]和当月展期增减[J]列，但没有专门的重组列。若行内按"重组"管理，不进展期列。

### 5.2 推断判断（需验证）

1. **G01_III期限分类变化**：推断——若短期贷款展期至1年以上，则从短期贷款[1.1]迁移至中长期贷款[1.2]。需确认展期重组后的原始期限。

2. **G09互联网贷款适用性**：推断——线上自动化流程可能符合互联网贷款定义，但需确认是否满足全部7个判断要素。特别是"以房产作为抵押物的抵质押贷款"排除条款——若本业务含房产抵押，则排除G09。

3. **五级分类具体落点**：推断——展期重组贷款原则上不低于次级类，但具体分类（次级/可疑/损失）取决于展期重组后的还款能力和担保覆盖程度。

4. **G12重组调整列[J]使用**：推断——若旧借据在年初为不良类，且新借据仍为不良类，则[J]重组调整列记录调整金额。需确认重组调整vs非重组调整的区分规则在智能展期重组场景下的适用性。

5. **G01_VII个人贷款分类**：推断——个人经营性贷款在G01_VII中进入[2.21.4]其他个人贷款，不进[2.1-2.20]行业分类。
