## 字段填报说明原文

| 序号 | 数据项编码 | 数据项名称 | 填报说明 |
| --- | --- | --- | --- |
| F1 |  | 数据日期 | 数据处理日期。 填写规则：日期格式：YYYY-MM-DD |
| F2 |  | 统一社会信用代码 | 报送数据金融机构法人的统一社会信用代码。 |
| F3 |  | 存贷利差 | 指填报机构平均贷款利率与平均存款利率之间的利率差。计算公式为：存贷利差=平均贷款利率-平均存款利率。平均贷款利率=各项贷款当月累计利息收入/当月日均贷款余额*12。平均存款利率=各项存款当月累计利息支出/当月日均存款余额*12。 填写规则：采用百分数表示，如利差为5.2%，填报5.2。若净利差为负数的，应显示负数。 |
| F4 |  | 付息负债利率 | 指填报机构所有付息负债按照当月日均余额计算的平均付息负债利率，平均付息负债利率=付息负债当月累计利息支出/当月日均付息负债余额*12。 填写规则：采用百分数表示，如利率水平5.2%，填报5.2。 |
| F5 |  | 生息资产利率 | 指填报机构所有生息资产按照当月日均余额计算的平均生息资产利率，平均生息资产利率=生息资产当月累计利息收入/当月日均生息资产余额*12。 填写规则：采用百分数表示，如利率水平5.2%，填报5.2。 |
| F6 |  | 净利差 | 指填报机构生息资产利率与付息负债利率之间的利率差，计算公式为：净利差=生息资产利率-付息负债利率。 填写规则：采用百分数表示，如净利差为5.2%，填报5.2。若净利差为负数的，应显示负数。 |
| F7 |  | 净息差 | 指填报机构所有生息资产和付息负债当月累计净利息收入与当月日均生息资产余额的比值，计算公式为：净息差=（当月累计生息资产利息收入-当月累计付息负债利息支出）/当月日均生息资产余额*12。 填写规则：采用百分数表示，如净息差为5.2%，填报5.2。若净息差为负数的，应显示负数。 |
