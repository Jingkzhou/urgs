## 字段填报说明原文

| 序号 | 数据项编码 | 数据项名称 | 填报说明 |
| --- | --- | --- | --- |
| F1 |  | 数据日期 | 数据处理日期。日期格式：YYYY-MM-DD。 填写规则：日期格式：YYYY-MM-DD |
| F2 |  | 存款账户编码 | 存款人按照有关法律法规在金融机构开立或使用的存款账户编码。 |
| F3 |  | 存款序号 | 存款吸收机构内部自行设置的，用于标识同一存款账户下不同笔存款的唯一编码。协定存款下结算户和协定户对应不同的利率水平，应该通过存款序号进行拆分。若存款账户编码已经能唯一识别，则该字段可默认填01。 填写规则：协定存款下结算户和协定户对应不同的利率水平，应该通过存款序号进行拆分。若存款账户编码已经能唯一识别，则该字段可默认填01。 |
| F4 |  | 内部机构号 | 金融机构自定义的唯一标识该笔业务经办机构（总行或分支机构）的内部编号。 |
| F5 |  |  | 金融机构自定义的唯一标识该客户的内部编号。 |
| F6 |  | 存款产品类别 | 存款根据契约特征进行的业务分类。应填写最底层类别。 填写规则详见"码值/校验/版本记录原文 - 存款产品类别"。 |
| F7 |  | 协议存款类型 | 若存款产品类别为D04-协议存款，需要按照存款人类型对特殊协议存款进行细分。 填写规则详见"码值/校验/版本记录原文 - 协议存款类型"。 |
| F8 |  | 起始日期 | 存款协议约定的起始日期。日期格式：YYYY-MM-DD。 填写规则：日期格式：YYYY-MM-DD。 |
| F9 |  | 到期日期 | 存款协议约定的到期日期。日期格式：YYYY-MM-DD。通知存款若到期日不能确定，一天、七天提前通知存款的协议到期日分别填写"1999-01-01"、"1999-01-07"。如业务类型为活期等业务没有到期日，留空。 填写规则详见"码值/校验/版本记录原文 - 到期日期"。 |
| F10 |  | 实际终止日期 | 存款协议的实际终止日期。日期格式：YYYY-MM-DD。仅业务结清时填报。 填写规则：日期格式：YYYY-MM-DD。仅业务结清时填报。 |
| F11 |  | 存款期限类型 | 存款协议约定的期限类型。 填写规则详见"码值/校验/版本记录原文 - 存款期限类型"。 |
| F12 |  | 定价基准类型 | 金融机构确定利率时所参考的基准利率类型，包括固定利率在定价时参考的利率类型。 填写规则详见"码值/校验/版本记录原文 - 定价基准类型"。 |
| F13 |  | 利率类型 | 指按照合同约定，该业务在存续期内的利率水平是否可以变动，若合同约定在持续期内利率不随任何条件变化而变化，则为RF01-固定利率，若在合约存续期间可根据特定条件一次或多次变更利率，无论其实际是否变动，均为RF02-浮动利率。 填写规则详见"码值/校验/版本记录原文 - 利率类型"。 |
| F14 |  | 实际利率 | 存款实际执行的年利率水平。采用百分数表示，如利率水平5.2%，填报5.2。对于定活两便存款，交易发生时无法获取利率信息的，根据上一年度定活两便存款发生额加权平均期限对应的存款利率填报。 填写规则：采用百分数表示，如利率水平5.2%， 填报5.2。对于定活两便存款，交易发生时无法获取利率信息的，根据上一年度定活两便存款发生额加权平均期限对应的存款利率填报。结构性存款填合同约定的保底收益率。 |
| F15 |  | 基准利率 | 指存款利率挂钩的最近一期存款基准利率、LPR 等基准利率值。固定利率存款按照合同发生时相应的基准利率种类和水平填报。采用百分数表示，如基准利率5.2%，填报5.2。 填写规则：固定利率和浮动利率均需填报。采用百分数表示，如基准利率5.2%，填报5.2。 |
| F16 |  | 利率浮动频率 | 存款的利率类型若为RF02-浮动利率，需要填报对应的利率浮动频率。 填写规则详见"码值/校验/版本记录原文 - 利率浮动频率"。 |
| F17 |  | 保底收益率 | 若结构性存款有约定保底收益率的，需要填报该字段。仅针对结构性存款。若结构性存款收益率固定，且没有高低之分，则填实际约定的收益率。 填写规则：仅针对结构性存款。若结构性存款收益率固定，且没有高低之分，则填实际约定的收益率。 |
| F18 |  | 最高收益率 | 若结构性存款有约定最高收益率的，需要填报该字段。仅针对结构性存款。若结构性存款收益率固定，且没有高低之分，则填实际约定的收益率。 填写规则：仅针对结构性存款。若结构性存款收益率固定，且没有高低之分，则填实际约定的收益率。 |
| F19 |  | 开户渠道 | 指存款账户通过何种渠道申请开立、办理，其中需要线下签订合同的存款统一归类为01-柜台办理。 填写规则详见"码值/校验/版本记录原文 - 开户渠道"。 |
| F20 |  | 异地存款标志 | 异地存款指银行等金融机构通过在没有设立实体网点的地市开立账户吸收的存款。若客户在银行等金融机构的实体网点开设的账户，其存款不算做异地存款，异地存款标志为N-否。若客户通过网上银行、手机银行等途径远程开立账户，但开立账户时定位的客户所在地市有该银行的实体营业网点，则该账户的存款也不算做异地存款，异地存款标志为N-否。若客户通过网上银行、手机银行等远程开立账户时定位的客户所在地市没有该银行的实体营业网点，则为异地存款，应填写为Y-是。 填写规则详见"码值/校验/版本记录原文 - 异地存款标志"。 |
| F21 |  | 大小额标志 | 大额存款指单笔存款余额大于或等于300 万美元或其他等值外币的存款；小额存款指单笔存款余额小于300 万美元或其他等值外币的存款。仅当币种为外币且存款产品类型为活期或协定存款时填写。 填写规则详见"码值/校验/版本记录原文 - 大小额标志"。 |

## 附件1：制度口径原文整理

非同业单位存款基础信息表填报金融机构报告期末存续的、当期结清的以及当期有发生额，且在金融机构资产负债表内核算的非同业单位存款账户信息。以存款账户下单笔存款协议为单位逐笔报送。业务币种仅统计人民币、数字人民币、美元、日元、欧元、港币业务。与非居民之间的业务可不报送。具体报送内容如下：
### F1 数据日期

数据处理日期。日期格式：YYYY-MM-DD。

### F2 存款账户编码

存款人按照有关法律法规在金融机构开立或使用的存款账户编码。

### F3 存款序号

存款吸收机构内部自行设置的，用于标识同一存款账户下不同笔存款的唯一编码。协定存款下结算户和协定户对应不同的利率水平，应该通过存款序号进行拆分。若存款账户编码已经能唯一识别，则该字段可默认填01。

### F4 内部机构号

金融机构自定义的唯一标识该笔业务经办机构（总行或分支机构）的内部编号。

### F13 利率类型

指按照合同约定，该业务在存续期内的利率水平是否可以变动，若合同约定在持续期内利率不随任何条件变化而变化，则为RF01-固定利率，若在合约存续期间可根据特定条件一次或多次变更利率，无论其实际是否变动，均为RF02-浮动利率。

| 代码 | 名称 | 说明 |
| --- | --- | --- |
| RF01 | 固定利率 | 指金融合约交易双方明确约定在该合约持续期间执行固定不变的利率。 |
| RF02 | 浮动利率 | 指依据金融合约交易双方约定或法律法规规定，在合约存续期间，可根据特定条件一次或多次变更利率。 |

### F14 实际利率

### F20 异地存款标志

异地存款指银行等金融机构通过在没有设立实体网点的地市开立账户吸收的存款。若客户在银行等金融机构的实体网点开设的账户，其存款不算做异地存款，异地存款标志为N-否。若客户通过网上银行、手机银行等途径远程开立账户，但开立账户时定位的客户所在地市有该银行的实体营业网点，则该账户的存款也不算做异地存款，异地存款标志为N-否。若客户通过网上银行、手机银行等远程开立账户时定位的客户所在地市没有该银行的实体营业网点，则为异地存款，应填写为Y-是。
