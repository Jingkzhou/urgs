# 利率报备监测分析系统-FTP变动明细信息表

- 所属系统：[[03-实体/利率报备监测分析系统|利率报备监测分析系统]]

- 采集方式：变化量
- 字段总数：6
- 原文依据：《附件1：利率报备数据采集制度（2026年版）》与《附件2：利率报备监测分析系统数据采集规范 V1.0.6》
- 原文页：[[01-资料库/利率报备监测分析系统/2026-05-19-FTP变动明细信息表-填报说明-原文|FTP变动明细信息表 填报说明-原文]]
- 知识沉淀位置：本页维护该报表的提炼结论、字段分组、重点规则和常见口径；字段全量清单保留在原文页。

## 报表定位

本表填报金融机构在报告期内存款、贷款、同业往来业务的 FTP（Funds Transfer Pricing，内部资金转移定价）价格曲线变动明细。业务币种仅统计人民币业务。是利率报备监测分析系统**首张 FTP 定价曲线变动明细表**，反映金融机构内部资金转移定价体系的期限结构和业务条线层面的利率曲线变化。

## 当前结论

- 本表是利率报备监测分析系统**第 31 张报表实体页**，也是系统内**首张 FTP 定价曲线变动明细表**。此前系统覆盖范围已包括贷款、存款、透支、同业往来和回购等多个业务维度的明细表和余额表，本表将覆盖范围扩展至**内部资金转移定价（FTP）曲线管理**维度。
- 6 字段覆盖**数据批次**（数据日期）、**法人标识**（统一社会信用代码）、**FTP 业务条线**（FTP业务类型，含存款/贷款/同业往来）、**期限维度**（期限类型，8 个标准期限+自定义）、**变动时点**（变动日期）和**定价水平**（FTP价格）。
- 本表不是业务发生额/余额明细表，而是**FTP 价格曲线变动事件表**——每行记录某业务条线下某一标准期限的 FTP 价格在某日的变动情况。与同系统存/贷款基础信息表的关系是：存/贷款基础信息表记录每笔存/贷款借据的**实际执行利率**，本表记录金融机构内部**FTP 价格曲线**（内部资金成本/收益基准）随市场或政策调整的变动。
- **FTP 业务类型**码值 3 类：A=存款、B=贷款、C=同业往来。与[[04-综合/利率报备监测分析系统-报表目录|目录]]中存款/贷款/同业往来各子系列对应，FTP 价格曲线按业务条线分别管理。
- **期限类型**为标准 FTP 曲线期限点：1个月、3个月、6个月、12个月、2年、3年、5年、10年。金融机构可按实际情况自定义其他期限，但需参照上述期限维度。
- **FTP 价格**为 D10.5 精度，5 位小数，应是年化利率百分数（如 2.375%），反映内部资金转移定价的价格水平。
- 本表采用**变化量**采集——每期报送全量存续 FTP 期限结构的变动明细，而非仅增量的变动。FTP 价格曲线在某日发生调整时，该日下所有受影响（含未变动的）业务条线+期限组合均需报送。
- 当前本表为**单表独立维度**，无配套的余额表或发生额表。FTP 价格曲线管理的本质是\"价格曲线变动事件\"，不同于存/贷款等业务数据表要求的三维覆盖（基础信息+余额+发生额）。

## 重点口径

- **报送范围**：金融机构在报告期内存款、贷款、同业往来业务的 FTP 价格曲线变动明细。业务币种仅统计人民币业务。
- **报送粒度**：以\"业务条线（FTP业务类型）+ 标准期限（期限类型）+ 变动日期\"为最小维度，每个组合一条记录。某日某业务条线下某期限的 FTP 价格发生变动时，该条线+期限+日期的组合为一行。
- **采集方式**：变化量——每期报送全部期末存续的 FTP 价格曲线变动明细数据。
- **FTP 业务类型细分规则**：码值包括 A=存款、B=贷款、C=同业往来三类主条线。如金融机构 FTP 定价对业务划分更细，可在主条线后加\"-自定义名称\"拆分报送。例如：个人存款和单位存款 FTP 价格不同时，可报送\"存款-个人存款\"和\"存款-对公存款\"两条数据。若一个 FTP 同时应用于多个业务条线，按业务条线分别报送。
- **期限自定义规则**：标准期限 8 档：1个月、3个月、6个月、12个月、2年、3年、5年、10年。如与实际情况不符，可自定义其他期限，但需参考上述码值（如\"15年\"、\"20年\"等合理延伸）。
- **FTP 价格**：D10.5 精度，百分数表示。为年化利率形式，如 FTP 价格 2.375% 填 2.375（10 位数字含 5 位小数）。
- **变动日期与数据日期**：变动日期（F5）是 FTP 价格实际变动日（如某日调整了 FTP 曲线），数据日期（F1）是数据处理日期，两者含义不同但均采用 YYYY-MM-DD 格式。

## 重点规则

- 统一社会信用代码（F2）报送金融机构法人（即报送机构自身）的统一社会信用代码，而非交易对手代码。本表不涉及交易对手维度的信息。
- FTP 价格（F6）采用百分数形式，如 FTP 年化价格 2.375% 填报 2.375（10 位数字含 5 位小数），与同系统贷款基础信息表和存款基础信息表中的实际利率字段填报规则一致。
- 某日某条线下某期限的 FTP 价格不变时，是否需要报送该行——按\"变动明细\"的命名规则，仅当 FTP 价格发生变动时才需报送。但从原文口径\"金融机构在报告期内存款、贷款、同业往来业务的FTP价格曲线变动明细\"推断，本表报告期内有变动的 FTP 价格曲线变动明细，非全量曲线快照。待确认。
- FTP 业务类型自定义细分时，使用连字符\"-\"拼接：如\"存款-个人存款\"、\"存款-对公存款\"。

### 跨系统关联

- 本表是利率报备系统特有报表，FTP 定价曲线管理在其他监管报送系统中尚无直接对应报表。同系统其他报表记录实际业务利率，本表记录内部资金转移定价曲线。

### 系列判断

- 本表为**单表独立维度**。FTP 价格曲线管理的本质是\"曲线变动事件\"，不同于业务数据系列（基础信息+余额+发生额的三维结构）。当前无配套余额信息表或发生额信息表。
