# 非居民涉税信息 — 账户报告

## 基本信息

| 项目 | 内容 |
|------|------|
| 系统 | [[03-实体/非居民金融账户涉税信息报送系统]] |
| 结构类型 | XML 报文主体（AccountReport + 子元素） |
| 核心元素数 | 12 个直接子元素 + Individual(11) / Organisation(6) / ControllingPerson(8) |
| 制约性 | 几乎全强制（仅 Payment 可选） |
| 可重复性 | 1 至无穷（每报文可含多个账户） |

## 结构定位

在 XML 层级中：`CNCRS → ReportingGroup → AccountReport`。

每个 AccountReport 代表一个非居民金融账户的完整信息，包括账户基本信息、持有人信息、收入信息和（条件性地）控制人信息。

## 账户持有人类型（AccountHolderType）路由

| 取值 | 含义 | AccountHolder 必须为 | ControllingPerson |
|------|------|:---:|:---:|
| CRS100 | 个人账户 | Individual | 禁止 |
| CRS101 | 有非居民控制人的消极非金融机构 | Organisation | 强制 |
| CRS102 | 非居民机构（不含消极非金融机构） | Organisation | 可选 |
| CRS103 | 非居民消极非金融机构，无非居民控制人 | Organisation | 可选 |

> 关键规则：既是中国税收居民又是其他国家（地区）税收居民的情形，按照非居民报送。

## 账户记录重复判定

同一开户银行法人、同一报告年度的两个记录，当**账号**和**账户持有人名称**同时相同时，判定为重复记录（RC1103）。

- 个人：名称指 LastName（姓）+ FirstName（名）
- 机构：名称指 OrganisationNameEN（英文名称）

## 表间关系

- AccountReport 的 DueDiligenceInd 必须与报文文件名首字母（P/N）一致
- AccountHolderType 为 CRS101 时，必须同时满足：AccountHolder=Organisation + 至少一个 ControllingPerson
- AccountHolderType 为 CRS100 时，AccountHolder=Individual 且禁止 Organisation/ControllingPerson
- DocSpec.DocRefId 的年度信息必须与 MessageHeader.ReportingPeriod 一致
