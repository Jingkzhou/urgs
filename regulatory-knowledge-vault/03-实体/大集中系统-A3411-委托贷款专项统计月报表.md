## 业务定位

A3411 是反映金融机构委托贷款资金来源和运用情况的专项统计月报表。通过三层分类体系（业务性质 → 交易对手大类 → 交易对手细分），系统监测委托贷款的规模和结构分布。

- 发放给个人（34R08）
- 发放给境外（34R09）

**受非金融机构委托（34R10 项下）：**
- 发放给广义政府（34R11）
- 发放给金融机构（34R12）

## 核心口径

- **现金管理项下委托贷款**：以委托贷款形式开展现金管理业务的账户间资金归集划拨、余额调剂、资金计价、资金清算等。
- **一般委托贷款**：传统意义上的委托贷款——委托人确定贷款对象、用途、金额、期限、利率等，金融机构代为发放、监督使用并协助收回。
- **住房公积金委托贷款**：住房公积金管理中心以公积金为资金来源，委托银行发放的住房消费贷款及保障性住房建设贷款。
- **广义政府**：通过政治程序建立的拥有立法、司法和行政权的法律实体及附属单位，包括中央政府、地方政府、机关团体、社保基金、部队和住房公积金。
- **金融机构委托贷款基金**：委托人为金融机构的委托贷款基金。
- **非金融机构委托贷款基金**：委托人为金融机构以外的单位或个人（包括广义政府、企业、个人等）的委托贷款基金。

## 校验关系

- **总量恒等式**：34R01（委托贷款总额）= 34R02（现金管理项下）+ 34R03（一般委托贷款）
- **基金恒等式**：34R18（委托贷款基金总额）= 34R19（现金管理项下基金）+ 34R20（一般委托贷款基金）
- **一般委托贷款拆分**：34R03 = 34R04（受金融机构委托）+ 34R10（受非金融机构委托）
- **金融机构委托基金拆分**：34R21 = 34R22 + 34R23 + 34R24 + 34R25 + 34R26 + 34R34 + 34R27
- **非金融机构委托基金拆分**：34R28 = 34R29 + 34R31 + 34R32 + 34R33
