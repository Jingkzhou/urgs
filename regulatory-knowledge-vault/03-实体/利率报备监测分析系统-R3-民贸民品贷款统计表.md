# 利率报备监测分析系统-R3-民贸民品贷款统计表

## 简介

民贸民品贷款统计表（报表编码 R3）是利率报备监测分析系统中首张**民贸民品贷款专项统计表**，以季报方式由人民银行各分支机构（而非金融机构法人）报送。本表统计口径为辖区内民贸民品贷款的贷款发生额、季末贷款余额和贴息额，以"时间 × 业务指标"矩阵表形式呈现。

本表与 R21-小额贷款公司发生额情况统计表、R22-小额贷款公司利率水平统计表同属于利率报备系统中由人民银行各分支结构填报的**汇总统计表（矩阵表式）**系列。

## 关键信息

- 所属系统：[[03-实体/利率报备监测分析系统|利率报备监测分析系统]]
- 报表编码：R3
- 报表名称：民贸民品贷款统计表
- 填报机构：人民银行各分支机构
- 报送频度及时间：季报，每季前5个自然日内报送上季度数据（遇周末顺延至下一工作日，遇国庆/春节等法定假日顺延至节后第二个工作日）
- 报送方式：通过利率报备监测分析系统以电子报表形式报送
- 数据单位：万元（金额保留两位小数）；利率保留五位小数
- 填报币种：以本外币合计人民币数据填报
- 字段总数：2（F1 一般说明 + F2 具体说明）
- 当前原文依据：《附件1：利率报备数据采集制度（2026年版）》与《附件2：利率报备监测分析系统数据采集规范 V1.0.6》
- 原文页：[[01-资料库/利率报备监测分析系统/2026-05-19-R3-民贸民品贷款统计表-填报说明-原文|R3-民贸民品贷款统计表 填报说明-原文]]
- 报表类型：汇总统计表（矩阵表式，非明细维度表）

## 当前结论

- 本表是利率报备系统中**非金融机构法人填报**的报表——填报主体为人民银行各分支机构，与 R21、R22 相同。
- 本表统计对象为**民贸民品贷款**，覆盖贷款发生额、季末贷款余额和贴息额三个业务指标。
- 矩阵表结构：
  - 行维度：1月-12月（按月排列，填报上季度数据时仅填对应月份）
  - 列维度：贷款发生额、季末贷款余额、贴息额
  - 每个单元格填报对应月份+对应指标的数据值
- 本表字段数仅2个（F1 一般说明 + F2 具体说明）。F1字段承载了报表元数据（报表名称/编码/填报机构/频度/单位/币种）和矩阵表样模板，F2字段承载具体口径定义。
- F2 具体说明为"无"，即本表无特殊口径说明，按矩阵表样直接填报即可。

## 重点口径

### 民贸民品贷款

民贸民品贷款是指对民族贸易企业和民族特需商品定点生产企业发放的贷款。

### 三个业务指标

| 指标 | 说明 |
|------|------|
| 贷款发生额 | 报告期内民贸民品贷款的发放金额（不含展期） |
| 季末贷款余额 | 报告期末民贸民品贷款的存续余额 |
| 贴息额 | 报告期内民贸民品贷款的财政贴息金额 |

## 重点规则

- 填报机构为**人民银行各分支机构**，非金融机构法人。
- 报送频度为**季报**，每季前5个自然日内报送上季度数据。
- 数据单位统一为**万元**；利率保留五位小数。
- 以**本外币合计人民币数据**填报。
- 本表三个列维度同期填报：同一月份同时列报贷款发生额、季末贷款余额和贴息额。
- 与 R21/R22 的差异：R3 矩阵列维度为业务指标（发生额/余额/贴息额），而非利率区间；R3 为季报，而 R21/R22 为月报。
