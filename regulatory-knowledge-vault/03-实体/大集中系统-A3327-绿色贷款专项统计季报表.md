## 报表定位

绿色贷款专项统计季报表（A3327）是人民银行大集中系统中监测金融机构绿色信贷投放的核心季报。统计范围覆盖按贷款用途、承贷主体及用途、承贷主体所属行业、资产质量四大维度的绿色贷款余额，并在附报中新增贷款户数、环境权益贷款和年减排二氧化碳当量环境效益指标。

## 关键概念定义

| 概念 | 定义 |
|------|------|
| 绿色贷款 | 支持环境改善、应对气候变化和资源节约高效利用的经济活动贷款，需确切证明符合规定用途 |
| 绿色产业贷款 | 满足《绿色金融支持项目目录》要求的七大产业贷款 |
| 绿色贸易贷款 | 用于绿色装备/产品收购、调销、储备、零售和批发的贷款（不含制造企业直接销售） |
| 绿色消费贷款 | 用于购买新能源汽车、绿色低碳建筑、节能环保认证产品和绿色农林业产品的贷款（不含贸易收购） |
| 境外绿色贷款 | 符合国际标准或实质上不低于国际标准的中国标准，用于境外项目的绿色贷款 |
| 一带一路绿色贷款 | 用于一带一路共建国家和地区的绿色贷款 |

## 关键口径规则

1. **重复统计避免**：同一笔贷款只能填报在绿色产业/贸易/消费的某一项指标中；多重用途时以金额份额最大的用途整体填报；部分用途符合目录时仅将能证明符合的部分纳入统计；不能确定的不纳入。
2. **年减排量折算**：以第三方审定材料披露的减排量为基础，按绿色贷款余额占项目总投资比例按年折算；仅贷款存续期间填报；缺少参考信息可不填报。
3. **户数去重**：共同还款人视为同一贷款客户，不作区别计算。
