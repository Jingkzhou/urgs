# 利率报备监测分析系统-人民币利差息差统计表

## 简介

人民币利差息差统计表是利率报备监测分析系统中首张**利率/利差/息差汇总统计表**，区别于其他明细维度表（基础信息/余额/发生额/交易流水），本表以机构法人为单位，统计报告期（月）的存贷利差、付息负债利率、生息资产利率、净利差和净息差五项核心利率汇总指标。

## 当前结论

- 本表是利率报备系统首张**利率/利差/息差宏观指标汇总表**，计算口径均基于月累计利息收支与月日均余额，以年化（*12）方式表达。
- 五项核心指标按从细到粗分为三层：
  - **单边平均利率层**：付息负债利率、生息资产利率（分别计算负债端和资产端的加权平均利率水平）
  - **净利差层**：净利差 = 生息资产利率 - 付息负债利率（反映资产与负债的利率差，不考虑两者的规模差异）
  - **存贷利差层**：存贷利差 = 平均贷款利率 - 平均存款利率（仅限存款与贷款，不包含其他生息资产/付息负债）
  - **净息差层**：净息差 = (生息资产利息收入 - 付息负债利息支出) / 日均生息资产余额 * 12（NIM，反映生息资产的净盈利能力，考虑规模差异）
- 所有利率/利差/息差指标均采用百分数表示，如5.2%填报5.2；负值显示负数。
- 数据日期为月末日期（YYYY-MM-DD），统一社会信用代码标识报送机构法人。
- 本表不包含字段码值，所有7个字段均为数值/标识字段。

## 重点口径

### 利率指标计算公式

| 指标 | 计算公式 | 备注 |
|------|----------|------|
| **存贷利差** | 平均贷款利率 - 平均存款利率 | 仅限贷/存款，不含其他生息资产/付息负债 |
| 平均贷款利率 | 各项贷款当月累计利息收入 / 当月日均贷款余额 * 12 | 年化处理 |
| 平均存款利率 | 各项存款当月累计利息支出 / 当月日均存款余额 * 12 | 年化处理 |
| **付息负债利率** | 付息负债当月累计利息支出 / 当月日均付息负债余额 * 12 | 含所有付息负债 |
| **生息资产利率** | 生息资产当月累计利息收入 / 当月日均生息资产余额 * 12 | 含所有生息资产 |
| **净利差** | 生息资产利率 - 付息负债利率 | 资产vs负债利差 |
| **净息差（NIM）** | (当月累计生息资产利息收入 - 当月累计付息负债利息支出) / 当月日均生息资产余额 * 12 | 净利息收入 / 日均生息资产，年化 |

### 范围口径定义（依据附件1制度口径原文）

#### F3 存贷利差的范围

**存款范围**（纳入利率报备采集制度统计范围）：
- 包括：单位和个人活期存款、定期存款、通知存款、定活两便存款、协议存款、协定存款、保证金存款、结构性存款、财政性存款、第三方存管存款及其他存款
- **不包括**：大额存单、应解汇款及临时存款等暂未纳入利率报备采集制度统计范围的存款

**贷款范围**（纳入利率报备逐笔采集范围）：
- 主要包括：贷款、贸易融资、票据贴现（不含买断式转贴现）、融资租赁、从非金融机构买入返售资产、透支、各项垫款、并购贷款及其他贷款

#### F4 付息负债利率的范围

**付息负债**指以支付利息为条件（或隐含利息条件，如发行零息债券）对外融入或吸收资金而形成的负债：
- 主要包括：各项存款、向中央银行借款、同业存放款项、同业拆入、卖出回购款项、存入保证金、应付债券
- 其他产生利息支出的负债：支出在利润表中计入"利息支出"项下的负债均应计入
- 隐含利息条件：虽不支付利息，但价值受实际利率影响（如发行零息债券）

#### F5 生息资产利率的范围

**生息资产**指以收取利息为条件（或隐含利息条件，如买入零息债券）对外融出或存放资金而形成的资产：
- 主要包括：存放中央银行款项、存放同业款项、各项贷款、拆放同业、债券投资、买入返售资产
- 其他产生利息收入的资产：收入在利润表中计入"利息收入"或"债券投资利息收入"项下的资产均应计入
- **排除**：免息期内的信用卡透支不计入生息资产，只有超出免息期且未停止计息的信用卡透支才属于生息资产

### 核心差异

- **存贷利差 vs 净利差**：
  - 存贷利差只关注**存款和贷款**（核心存贷业务）
  - 净利差关注**所有生息资产和所有付息负债**（涵盖存放央行、同业往来、债券投资等）
  - 两者为互补关系，共同反映机构的定价能力

- **净利差 vs 净息差**：
  - 净利差 = 生息资产利率 - 付息负债利率（利率差，不考虑资产/负债规模差异）
  - 净息差 = 净利息收入 / 日均生息资产余额（考虑资产和负债的规模差异，但分子是差额）
  - 当生息资产规模 > 付息负债规模时，净息差通常 < 净利差

## 重点规则

- 业务币种仅统计**人民币**业务。
- 所有利率指标均采用**百分数**填报（如5.2%填5.2）；非百分数可直接填报。
- 负值须显示负数符号。
- 本表为全量采集，**非变化量/增量**，每期按机构法人汇总计算后报送一条或多条记录。
- 数据来源为本系统内各存贷款明细表的汇总数据，或行内总账/管理会计系统的月均余额与累计利息数据。
