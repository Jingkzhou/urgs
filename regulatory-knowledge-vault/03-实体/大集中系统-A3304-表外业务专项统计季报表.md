# 大集中系统-A3304-表外业务专项统计季报表

## 简介

A3304 是人民银行大集中金融统计监测管理信息系统中的表外业务专项统计季报表（季度报送），用于全面反映金融机构表外业务发展情况，涵盖担保类、承诺类、金融资产服务类、金融衍生品类四大类表外业务统计，以及与中间业务收入的整合统计。

> 2024年修订全面整合表外业务统计季报和商业银行中间业务统计季报，指标框架大幅调整。

## 关键信息

- **所属系统**：大集中系统
- **报表编码**：A3304
- **报表名称**：表外业务专项统计季报表
- **报送频度**：季度
- **数据属性**：余额属性（业务量指标中"代理代销业务"（33945）及其子项、银行收益指标用余额属性报累计发生金额；其他指标报期末余额）
- **业务类/币种**：本外币
- **当前原文依据**：[[01-资料库/大集中系统/2026-05-18-A3304-表外业务专项统计季报表-原文|2026-05-18 A3304 原文]]
- **知识沉淀位置**：本页维护该报表的提炼结论、重点规则和常见口径

## 当前结论

### 报表定位

- A3304 是人民银行表外业务专项统计制度下的核心季报，覆盖金融机构各类表外业务（担保、承诺、金融资产服务、金融衍生品）的全景统计。
- 2024 年修订将原表外业务统计季报与商业银行中间业务统计季报全面整合，统一纳入 A3304 指标框架。
- 2023 年修订将"表外理财"统一更名为"非保本理财"。

### 表外业务四大分类

| 分类 | 业务类型 | 典型业务 |
|------|----------|----------|
| 担保类 | 接受客户委托对第三方承担责任 | 承兑汇票、信用证、保函、信用风险仍在银行的销售与购买协议 |
| 承诺类 | 未来按约定条件提供信用业务 | 贷款承诺、未使用的信用卡授信额度 |
| 金融资产服务类 | 资产管理与投融资服务 | 表外理财、资产托管、委托贷款、委托投资、债券承销、代理代销等 |
| 金融衍生品类 | 价值取决于基础资产/指数的合约 | 远期、期货、掉期（互换）、期权（名义本金期末余额） |

### 保函分类体系

- **融资性保函**：资金融通为目的，包括借款保函、融资租赁保函、透支保函、有价证券发行担保、一年期以上延期付款保函、以货币偿还的补偿贸易保函、银行授信额度保函、融资性备用信用证（含保兑信用证）
- **非融资性保函**：非融资性经营活动，包括投标保函、履约保函、预付款保函、海事保函、质量保函、关税付款保函、工程维修保函、诉讼保函、提货担保保函
- **置换预售监管资金的保函**：向房企出具的，用于置换预售监管资金的保函

### 委托投资分类

- **金融机构委托投资**：委托人为金融机构
- **非金融机构委托投资**：委托人为除金融机构以外法人或个人

### 中间业务收入分类

| 收入类型 | 说明 |
|----------|------|
| 国际结算收入 | 单位/个人国际结算业务手续费 |
| 国内结算收入 | 单位/个人国内结算业务手续费 |
| 保理费收入 | 应收账款转让后提供融资及管理服务收入 |
| 银团贷款收入 | 安排费、承诺费等 |
| 代客外汇买卖收入 | 代客外汇买卖手续费佣金 |
| 银行卡业务收入 | 消费、转账、存取现金手续费 |
| 电子银行业务收入 | 电子银行服务费 |

### 关键口径

- **银行收益指标**：填报各项表外业务对应产生的手续费及佣金收入，不考虑对应支出。
- **发行非保本理财产品**（2023年更名前为"表外理财"）：银行填报银行非保本理财产品期末募集资金余额；信托公司填报信托产品期末募集资金余额。
- **其他金融资产服务业务**：如果金额占（发行表外理财产品+委托贷款+委托投资+资产托管）>=5%，须将主要业务内容材料报送至人民银行调查统计司。
- **财务顾问咨询**：业务量指标不填报数据，收益指标填报该项业务收入。
- **债券承销**：按实际承销份额的面值填报。

## 重点规则

### 数据属性规则

业务量指标中"4.代理代销业务"（33945）及其子项、银行收益指标：用余额属性报送**从年初至报告期末的累计发生金额**；其他指标：报送**报告期末余额**（备注不填报数据的指标除外）。

### 合并折算规则

- 报送以人民币计值的本外币合计数据
- 外币折算人民币：按报告期末最后一天国家外汇管理局公布的人民币兑美元、欧元、日元、港币基准汇价折算
- 其他币种：以报告期末最后一天美元对人民币基准汇率与同天上午9:00国际外汇市场其他货币兑美元汇率套算
