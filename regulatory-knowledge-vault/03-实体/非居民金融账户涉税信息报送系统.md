# 非居民金融账户涉税信息报送系统

## 系统定位

本系统是基于《非居民金融账户涉税信息尽职调查管理办法》（2017年第14号公告）建立的非居民金融账户涉税信息自动交换报送体系。银行通过 TLQ 消息中间件向人民银行报送非居民金融账户涉税信息 XML 报文，经人行和税总两级校验后，参与 OECD《金融账户涉税信息自动交换标准》（AEOI/CRS）的国际信息交换。

## 系统概况

### 法规依据

- 《非居民金融账户涉税信息尽职调查管理办法》（国家税务总局、财政部、中国人民银行、银监会、证监会、保监会公告 2017 年第 14 号）
- 银科技〔2025〕17 号《银行业存款类金融机构非居民金融账户涉税信息报送接口规范 V4.0》

### 数据交换架构

- **传输层**：TLQ 消息中间件（TongLINK/Q V8.1）
- **节点号**：复用全国集中银行账户管理系统节点号
- **报文格式**：XML 1.0，UTF-8 编码
- **报文类型**：批量报文 + 回执报文

## 核心数据结构

本系统采用 XML 树形报文结构，非传统数据库表结构。以 `AccountReport`（账户报告）为核心，每个账户报告包含：

- **账户标识**（DocSpec、AccountNumber、OpeningFIName）
- **账户状态**（ClosedAccount、DueDiligenceInd、SelfCertification）
- **账户余额**（AccountBalance）
- **账户持有人**（Individual 或 Organisation，二选一）
- **控制人信息**（ControllingPerson，CRS101 时强制）
- **账户收入**（Payment，可选）

### 文件命名规则

```
<cams报文类型><前缀RE><14位金融机构编码><报告年度YYYY><P/N+8位序号>.dat
```

例：`cams01300101REC12345678901232018N00000001.dat`

- P：存量账户（存量账户尽职调查规则）
- N：新开账户（新开账户尽职调查规则）

## 关联系统

- **利率报备监测分析系统**：该系统的存/贷款和同业往来业务中均明确「与非居民之间的业务可不报送」，本系统为这些豁免业务的专项报送渠道。
- **全国集中银行账户管理系统**：复用节点号和国籍代码表（附表3）。
- **反洗钱系统**：同为涉及客户身份识别的监管报送，均需收集客户尽职调查信息，但目的不同（涉税信息交换 vs 反洗钱监测）。

## 关键特点

1. **XML 树形报文**（非数据库表，不存在物理表名）
2. **国际标准**：基于 OECD CRS（Common Reporting Standard），需对接缔约国税务信息交换
3. **两组码表体系**：
   - 国籍/税收居民国代码（附表3，排除 ANT/XKD/XLE/ZZZ）
   - 纳税人识别号格式（各国 TIN 规范，参考 chinatax.gov.cn/aeoi_index.html）
4. **三层校验流程**：银行自校验 → 人行校验（cams.016） → 税总校验（cams.017）
5. **错误代码分为两类**：
   - FC（File-level Check）：文件级错误
   - RC（Record-level Check）：记录级错误
6. **代报机制**：允许发起行代村镇银行等被代报机构报送
