## 报表定位

本表反映银行业金融机构金融精准扶贫贷款情况，包括个人精准扶贫贷款和单位精准扶贫贷款的规模、用途、期限、担保方式、财政贴息等内容，以及附报的贷款笔数、带动服务人数、已脱贫人口贷款等信息。原名"金融精准扶贫贷款专项统计"，现更名为"金融精准帮扶贷款专项统计"。

## 关键概念定义

### 核心分层

| 概念 | 说明 |
|------|------|
| 金融精准扶贫贷款 | 向建档立卡贫困人口发放，或向其他主体发放但具有扶贫带动服务作用的贷款 |
| 贫困人口 | 建档立卡贫困人口 + 已脱贫人口 |
| 建档立卡贫困人口 | "A17识别标准"为"国家标准"，"脱贫状态"为"返贫/未脱贫/预脱贫" |
| 已脱贫人口 | "A17识别标准"为"国家标准"，"脱贫状态"为"已脱贫享受政策"（2018.4.1后不含"已脱贫不再享受政策"） |

### 扶贫带动作用认定标准

**其他个人精准扶贫贷款（认定条件之一）**：
1. 吸纳1个（含）以上建档立卡贫困人口就业
2. 与1个（含）以上建档立卡贫困人口签订帮扶协议或交易协议
3. 有1个（含）以上建档立卡贫困人口参股

**产业精准扶贫贷款（认定条件，按企业规模分档）**：
| 企业类型 | 就业人数要求 | 参股要求 | 帮扶协议要求 |
|----------|-------------|---------|-------------|
| 微型企业 | 1个（含）以上 | 1个参股 | 1份协议 |
| 小型企业 | 3个（含）以上，或≥职工2% | 1个参股 | 3份协议 |
| 中型企业 | 5个（含）以上，或≥职工2% | — | 5份协议 |
| 大型企业 | 10个（含）以上，或≥职工2% | — | 10份协议 |
| 农民专业合作社 | 1个（含）以上 | 1个参股 | 1份协议 |
| 其他非企业单位 | 1个（含）以上 | — | 1份协议 |

> 企业划型标准按《中小企业划型标准规定》（工信部联企业〔2011〕300号文）。

### 项目精准扶贫贷款门槛

| 项目类型 | 贫困人口占比要求 |
|----------|-----------------|
| 农田基本建设 | ≥10%（地区户籍人口） |
| 生态环境改造 | ≥10% |
| 农村基础设施 | ≥10% |
| 交通设施 | ≥10%，明确为县级及以下公路 |
| 农网升级改造 | ≥10% |
| 水利设施 | ≥10% |
| 教育贷款 | 该校学生中占比≥10% |

### 脱贫人口相关认定（附报7-10）

附报7-9贷款对应脱贫人口的带动认定标准，按企业规模分档要求及帮扶带动条件，与上述产业精准扶贫贷款框架一致，但面向对象为"脱贫人口"而非"建档立卡贫困人口"。

## 重要规则

1. **主报 vs 附报区分**：主报统计对象仅限建档立卡贫困人口；附报7-9合并考察建档立卡贫困人口和已脱贫人口，且不包含应在主报统计的贷款，不重复统计。
2. **2022年起发生额限制**：主报及附报1-2，9.1及其子项原则上不应填报发生额，如填报需提交说明。9.1带动服务原建档立卡贫困人口的人数，2022年起原则上不应有发生额。
3. **识别信息更新不追溯调整**：以国务院扶贫办最新识别信息为依据，信息更新前发放的贷款不做追溯调整。
4. **贷款不含票据贴现**。
5. **担保方式优先原则**：多种担保方式并存时，抵（质）押担保方式优先。
6. **新型经营主体归属优先**：同时被认定为家庭农场时，贷款优先填报在"农民专业合作社贷款"或"农业产业化龙头企业贷款"项下，不得重复统计。
7. **余额和发生额**：余额属性填报报告期末存续数据，发生额属性填报年初至报告期末累计发生数据。
8. **附报3（已脱贫人口贷款）** 不应向"已脱贫不再享受政策"人口发放的贷款。
