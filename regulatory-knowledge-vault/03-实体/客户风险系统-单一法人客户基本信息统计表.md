# 客户风险系统-单一法人客户基本信息统计表

## 简介

本表采集单一法人客户的基本信息以及商业往来类关联人、主要股东及主要关联企业信息，是客户风险统计中客户主数据的基础信息来源。

## 关键信息

- 所属系统：[[03-实体/客户风险系统|客户风险系统]]
- 报表编码：待确认
- 报表名称：单一法人客户基本信息统计表
- 当前原文依据：《中国银监会办公厅关于印发新版客户风险统计报表填报细则的通知》（银监办发[2014]201号，2014年7月）第22-25页
- 知识沉淀位置：本页直接维护该报表的提炼结论、重点规则和常见口径

## 当前结论

- 本表以单一法人客户为主体，采集其基础身份信息、上市情况、预警评级、财务指标等基本信息。
- PART II 商业往来类关联人信息与表2（对公及同业客户授信和表内外业务统计表）存在关联，业务往来类关联人信息一般根据表2相关指标填报。
- PART III 覆盖股东及关联企业，涉及股权填报规则和关联企业填报规则。

## 重点口径

### PART I：单一法人基本情况

| 字段 | 口径说明 |
|------|----------|
| 组织机构代码 | 客户的统一社会信用代码或组织机构代码 |
| 上市情况 | 多个上市公司情况用英文半角分号分隔；中方控股、仅限于公司制企业等口径参见原文 |
| 风险预警信号 | 客户当前的风险预警状态 |
| 关注事件 | 客户相关的关注事件记录 |
| 财务指标 | 对于大型企业及企业在表1 PART III贷款类型中贷款、贸易融资、法人账户透支任意一项余额不为零的，应填报财务指标；财务指标应来源于同一时点、同一口径的报表 |
| 贷款卡号 | 客户的贷款卡编号 |

### PART II：商业往来类关联人信息

| 字段 | 口径说明 |
|------|----------|
| 关联类型 | 商业往来关联人的类型分类 |
| 业务往来类关联人信息 | 一般根据表2（对公及同业客户授信和表内外业务统计表）相关指标填报 |

### PART III：主要股东及主要关联企业

| 字段 | 口径说明 |
|------|----------|
| 股权填报规则 | 股东持股比例的填报规则 |
| 关联企业填报规则 | 关联企业的认定和填报规则 |
| 股东/关联企业名称 | 股东或关联企业的全称 |
| 股东/关联企业类型 | 股东或关联企业的类型分类 |
