## 报表定位

本表填报金融机构报告期内透支业务（仅包括信用卡透支及花呗、京东白条等其他类信用卡业务，含类信用卡业务性质的信托贷款）的**本金发放、收回交易**，不包括利息、手续费交易。按数据日期、客户号、内部机构号、账号、交易日期、交易类型、币种、交易方向、分期方式、实际利率、基准利率等维度分类汇总报送。业务币种仅统计人民币、美元、日元、欧元、港币业务。与非居民之间的业务可不报送。

## 当前结论

- 本表是利率报备监测分析系统中**透支业务维度唯一的交易流水表**，覆盖信用卡透支及类信用卡（花呗、京东白条、类信用卡信托贷款）业务的本金发放与收回交易事件。
- 本表仅报送**本金**交易，不包括利息、手续费交易——与同系统[[03-实体/利率报备监测分析系统-透支业务余额信息表|透支业务余额信息表]]的余额口径（不含利息、手续费及已转表外资产余额）一致。
- **3-in-1 结构**：本表内部包含**三张子表**，以 46 个字段（14+18+14）组成同一报表：
  1. **交易流水表**（14 字段）——按数据日期、客户号、内部机构号、账号、交易日期、交易类型、币种、交易方向、分期方式、实际利率、基准利率等维度报送每笔本金发放/收回交易的基本要素。其中"所属账单编号"和"交易到期日期"两字段暂停报送。
  2. **账单信息表**（18 字段）——按账单周期报送透支账单级信息，覆盖账单编号、出单日期、币种、账单总金额、本期应还款总额、分期金额、计息本金、账单到期日期、计息利率、分期标识、利息总计、最小还款额、还款金额及已逾期金额。
  3. **分期信息表**（14 字段）——按分期业务报送分期付款明细信息，覆盖分期付款序号、总分期期数、币种、每月分期付款金额、分期本金总金额、分期开始/最终到期日期、分期付款利率、分期方式及免息期。
- 本表仅覆盖**本金发放、收回交易**事件，不覆盖利息、手续费交易——区别于透支业务余额信息表按账号+透支业务类型报送的**余额快照**。
- **附件1 F5 交易日期**在字段总表原文中序号5数据项名称为空（该行未命名），但附件1 明确 F5 为"交易日期"（日期格式：YYYY-MM-DD，非空校验，不可强制提交）。该字段在字段总表原文中疑似缺失但附件1 中有明确定义。

## 重点口径

- **报送对象**：报告期内透支业务的本金发放、收回交易，不包括利息、手续费交易。
- **业务范围**：仅包括信用卡透支及花呗、京东白条等其他"类信用卡"业务（含类信用卡业务性质的信托贷款）。
- **报送维度**：按数据日期、客户号、内部机构号、账号、交易日期、交易类型、币种、交易方向、分期方式、实际利率、基准利率等维度分类汇总报送。
- **币种范围**：仅统计人民币、美元、日元、欧元、港币业务。
- **非居民业务**：与非居民之间的业务可不报送（可选不报）。
- **交易方向**：导致透支余额增加的为 1-发放，导致透支余额减少的为 0-收回。
- **分期方式码值**：应填写最底层类别（如 B01-账单分期/B02-专项分期/B03-其他分期），不含向上回溯。
- **实际利率**：交易发生时实际执行年利率，百分数表示；无免息期直接计息填实际执行年化利率；有免息期填合同约定免息期后利率（不含逾期利率）。
- **基准利率**：仅浮动利率填报，固定利率不需填报；百分数表示。
- **附件1 F5 交易日期**：交易实际发生日期，YYYY-MM-DD，非空校验，不可强制提交。

## 重点规则

### 暂停报送字段
- 交易流水表的"所属账单编号"和"交易到期日期"为**暂停报送**状态。
- 交易到期日期字段说明：分期交易指分期最终到期日；普通未分期交易指约定账单到期日期；还款交易填对应原账单到期日期，无法拆分时填最晚账单到期日期。

### 字段总表序号5缺失
- 字段总表原文中第一张子表的序号5（介于"账号"和"交易类型"之间）全部为空。附件1 F5 明确为"交易日期"——交易实际发生日期（YYYY-MM-DD，非空校验，不可强制提交）。该缺失可能是字段总表原文转录遗漏或 PDF 截断导致，暂以附件1 F5 为准。

### 分期信息表的分期方式码值范围
- 分期信息表（子表3）的分期方式码值**不含 Z-未分期**（仅 A/B01/B02/B03），因为该子表只报送已确认的分期业务；交易流水表（子表1）的分期方式含 Z-未分期，因为覆盖未分期交易。

### 分期标识码值歧义
- 原文中分期标识码值表显示：
  | Y | 是 |
  | N | 否按最低还款额还款的默认为 |
  | N | 否 |
  其中第二行 N 的"名称"列写作"否按最低还款额还款的默认为"，第三行为"否"。这可能是原文排版错误，第二行 N 的意思应是"按最低还款额还款的默认为 N（否）"。附件2 中填写规则写为"Y-是 N-否 按最低还款额还款的默认为N-否"，可佐证两个 N 实际是同一个码值的重复。
