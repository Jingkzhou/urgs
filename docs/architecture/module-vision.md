## 1. auth — 认证授权

### 现状
- JWT Bearer Token 认证
- RSA SSO 单点登录
- OAuth2 授权码模式（基础）
- 用户-角色关联

### 终极目标：**零摩擦、零风险的统一身份中枢**

- **无感登录**：支持 OAuth2 全模式（authorization_code / password / client_credentials），支持企业微信/飞书/Okta 等主流 IdP 接入
- **主动安全**：Refresh Token 机制、Token 主动吊销（登出/踢人）、登录失败限流、异常地点登录告警
- **细粒度会话管理**：用户可查看所有活跃会话、支持按设备/地点管理会话
- **企业级安全**：多因素认证（TOTP/短信）、密码策略（强度/过期/历史）、SSO 单点登出（SLO）
- **审计完整**：所有认证行为（登录/登出/Token 刷新）全程审计，支持合规报表导出

## 3. ai — AI 功能

### 现状
- SSE 流式聊天接口
- 聊天会话管理（创建/列表/删除/标题生成）
- 多种 Agent 构建模式（RAG / DIFY / AGENT_APP）
- AI 使用日志、API 配置管理
- 血缘报告 AI 生成

### 终极目标：**数据团队的 AI 首席助理**

- **对话即操作**：用户用自然语言完成元数据查询、任务配置、SQL 审核等操作，AI 直接调用系统 API 执行
- **监管智能解读**：上传监管规则文档，AI 自动解读并映射到内部元数据，生成合规差异报告
- **主动预警**：AI 持续监控任务执行异常、数据质量波动，主动推送预警与修复建议
- **多模型适配**：支持 OpenAI / Claude / 文心 / 本地模型，用户可切换；支持模型能力对比评测
- **Agent 市场**：内置监管报送、数据质量、SQL 优化等场景化 Agent，支持用户自定义 Agent 并分享
- **完整审计**：所有 AI 交互记录可追溯，支持反馈闭环（点赞/踩）持续优化

- **共享空间**：支持团队知识库与个人知识库，权限细粒度控制（查看/编辑/管理）

## 6. lineage — 血缘分析

### 现状
- SQL 静态解析获取表级/字段级血缘
- 血缘分析记录管理
- 血缘审核（LineageReview）
- 血缘图谱存储（Neo4j）

### 终极目标：**全链路、全方言、可自修复的血缘引擎**

- **运行时血缘补全**：通过数据库审计日志/ETL 执行日志采集运行时血缘，与静态分析互补，覆盖率 > 95%
- **全方言支持**：MySQL / PostgreSQL / Oracle / SQL Server / Hive / Spark SQL / ClickHouse，统一解析能力
- **字段级血缘精确化**：处理 CTE、子查询、CASE WHEN、UNION 等复杂场景，精确追踪每个字段的来源
- **血缘影响可视化**：点击任意表/字段，展示完整上下游链路，支持路径高亮、导出报告
- **变更影响模拟**：模拟某字段变更后的影响范围，在发布前给出预警
- **血缘自修复**：检测到血缘断链时，AI 辅助推荐修复方案，审核通过后自动补全
- **血缘质量评分**：评估血缘覆盖度、准确度，驱动持续完善

## 7. quartz — 定时任务调度

### 现状
- 定时任务定义（Cron / 简单触发）
- 任务依赖管理
- 任务执行日志
- 任务状态管理

### 终极目标：**自愈、可观测、智能化的企业调度中枢**

- **分布式高可用**：多节点部署，任务故障自动转移，支持任务分片并行执行
- **智能调度**：基于历史执行时长自动推荐 Cron 表达式，避免任务重叠；资源紧张时自动排队
- **依赖智能推断**：基于血缘关系自动推荐任务依赖，减少人工配置
- **执行自愈**：失败自动重试（可配置策略）、超时自动 Kill、下游任务自动阻断
- **全链路可观测**：任务执行 Gantt 图、资源消耗趋势、SLA 达成率统计
- **告警闭环**：执行失败/超时/跳过，自动通知（企微/邮件/Webhook），并处理响应状态

## 20. urgs-agent — AI Agent 运行时

### 现状
- Python FastAPI 服务
- 与 Dify 平台集成
- RAG 检索增强
- Agent Skill 管理

### 终极目标：**可自主规划、可工具调用、可持续学习的 Agent 平台**

- **工具调用框架**：Agent 可自主调用系统 API（元数据查询/任务触发/血缘分析），真正实现「对话即操作」
- **多 Agent 协作**：监管解读 Agent、数据质量 Agent、SQL 优化 Agent 等协作完成复杂任务
- **长期记忆**：Agent 拥有跨会话记忆，记住用户偏好和历史决策
- **人机回环**：关键操作（如删除任务/修改元数据）需用户确认，安全可控
- **Agent 评估框架**：量化 Agent 的决策质量，持续自我优化
- **本地模型支持**：支持 Llama / Qwen 等本地模型部署，降低 API 成本

---

## 21. sql-lineage-engine — SQL 血缘引擎

### 现状
- 基于 JSqlParser 的 SQL 解析
- 表级血缘提取
- 字段级血缘提取（基础场景）
- 多方言支持（部分）

### 终极目标：**业界领先的开源 SQL 血缘解析引擎**

- **完整覆盖复杂 SQL**：CTE / 子查询 / 窗口函数 / PIVOT / UNNEST 等场景完整支持
- **多引擎方言库**：MySQL / PostgreSQL / Oracle / Hive / Spark / ClickHouse 独立方言处理器
- **可插拔解析器**：支持用户自定义解析规则，适配内部 SQL 变种
- **血缘置信度评分**：对解析结果给出置信度，低置信度提示人工审核
- **批量分析**：支持整个数据库的存储过程/视图/ETL 脚本批量分析
- **独立 API 服务**：可独立部署为 HTTP 服务，供其他系统调用（不依赖 URGS 主系统）
- **开源社区**：核心引擎开源，建立社区生态，持续吸收各方贡献
