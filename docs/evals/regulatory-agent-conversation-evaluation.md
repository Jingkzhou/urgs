# 监管 Agent 多轮对话与查询评测

## 目标

验证监管数据查询助手、监管知识助手和 Router 在真实多轮场景中的上下文继承、能力边界、相对日期、确定性分析和知识切换行为。

## 最终结果

| 评测集 | 结果 | 说明 |
|---|---:|---|
| 多轮路由 | 45/45 | 15类问题连续3轮 |
| 监管数据查询 | 13/13 | 含目录、期间、汇总、明细、分析、多轮、安全和相对日期 |
| 监管知识 | 31/31 | 主结果29题通过，2题使用修复后定向复测结果 |

## 问题、原因与解决方案

| 问题 | 原因 | 解决方案 | 验证 |
|---|---|---|---|
| 数据查询后追问“都能查哪些指标”可能切到知识助手 | Router 未明确区分实际可查询目录和知识覆盖范围 | 数据查询会话中的指标、系统、表、日期续问优先复用数据查询助手；口径、定义、报送要求才切知识助手 | 路由15类问题连续3轮，45/45 |
| 独立 Router 接口与聊天编排行为可能不一致 | `/v1/router/route` 保留旧的独立提示与模型调用 | 接口统一调用 `run_router` | 服务测试及路由评测通过 |
| 查询指标可用日期时遗漏指标条件 | Agent 退化为查询整张表的期间 | Skill 要求已明确指标时必须传 `indicator_codes` | RDQ-003 从0.90修复到1.00 |
| “今年走势”由模型自行计算差额和变化率 | 多期汇总值被模型直接推导 | 走势、变化、环比等必须调用指标画像和确定性对比工具 | RDQ-012 定向复测1.00 |
| 目录为空后尝试翻查文件或用知识范围替代数据目录 | 缺少空目录停止规则 | Skill 要求目录为空立即停止，禁止改用文件工具或声称未返回系统已接入 | Skill测试与目录边界规则通过 |
| 300万元单笔贷款被当作单户授信总额判断S71 | 混淆贷款金额与授信口径 | 知识助手增加硬性口径边界，缺少单户授信总额时只能条件命中或待确认 | RK-012 定向复测1.00 |
| 宽泛知识问题偶发递归上限 | 评测脚本使用通用图预算100，未使用知识助手专用预算240 | 评测改用 `agent_graph_config`，并提示跨系统评估避免逐页穷举 | RK-016 连续定向复测通过 |
| 否定句和同义表达被评分器误判 | 禁词采用简单子串，正确回答措辞范围过窄 | 只禁止错误肯定结论，增加逻辑等价正确表达 | 重评分后对应问题通过 |
