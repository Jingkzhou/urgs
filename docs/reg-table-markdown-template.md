# 监管报表 Markdown 模版

## 设计目标

- 一张报表一个 Markdown，适合归档、评审、知识库收录。
- 报表级信息、字段级信息、码值明细放在同一文档里，避免来回跳转。
- 先总览，再细节，再码值，适合业务、研发、测试共同阅读。

## 推荐目录结构

```text
reg-table-docs/
├── README.md
└── tables/
    ├── 001_SYS_G0101_资本充足率总表.md
    ├── 002_SYS_G0102_贷款明细表.md
    └── ...
```

## 可读性建议

- 一级标题只放报表名，便于文档系统检索。
- 报表概览用二维表，字段总览用横表，字段细节按字段逐段展开。
- 码值不要单独跳文档，直接挂在字段下面，阅读链路最短。
- SQL、公式、代码片段统一用 fenced code block，避免长文本挤进表格。
