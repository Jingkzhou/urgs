# 监管集市智能助手多场景评测报告

## 结论

第一阶段智能助手已完成 31 个真实场景评测，最终确定性门禁通过率为 **31/31（100%）**。评测直接调用当前配置的真实模型、监管集市运行时 Skill 和本地监管集市 API，没有使用模拟回答或模拟工具结果。

历史基线为 18/30。当前 31 个场景平均耗时为 13.67 秒，工具调用总数为 106 次。历史基线最差场景 RMA-022（G01 缺少物理绑定仍要求开发 SQL）由 89.70 秒、39 次工具调用下降到 18.71 秒、9 次工具调用，并能在证据不足时明确停止。

## 发现与修复

| 问题 | 根因 | 修复 |
|---|---|---|
| Skill 偶尔无法加载 | 运行时 Skill 根目录配置不一致 | 统一使用 `DEEPAGENTS_SKILLS_ROOT` 定位仓库 Skill |
| 缺少物理绑定时反复搜索 | 模型没有确定性终止条件 | 检测全部候选表无物理绑定后直接输出待确认项，禁止继续猜测或校验 SQL |
| 单题最多出现 39 次工具调用 | 探索工具缺少循环和总量约束 | 增加重复调用检测、探索切换阈值和 14 次业务工具硬上限 |
| Agent 可见工具之外仍可能被调用 | 只隐藏了工具描述，没有执行期校验 | 在工具执行前再次验证可见性并拒绝隐藏工具 |
| 可能引用历史代码中的物理表 | 工具结果携带历史代码片段 | 递归剔除 `codeSnippet`，只允许使用当前资产绑定证据 |
| 在无关系证据时猜测 JOIN | 同名字段和主键被模型当作关系 | 关系工具无已维护 JOIN 键时确定性拒绝生成 JOIN SQL |
| 指定表的开发上下文混入无关表 | 关键词搜索结果与显式表 ID 合并 | 显式表 ID 存在时，关键词只补充这些表下的字段 |
| 码值校验接口返回 500 | Python 参数使用 `table_code`，后端要求 `tableCode` | 统一为后端 DTO 的驼峰字段名 |
| 用户要求校验时偶尔跳过工具 | 最终回答完全依赖模型自行决定 | SQL 校验请求强制调用 `validate_generated_sql` |
| 最终回答只给校验报告、漏掉 SQL | 模型在工具结果后没有回显已校验 SQL | 从最近一次校验调用恢复 SQL，并补齐指标设计卡与 SELECT 草稿 |
| 日期缺失仍生成无日期 SQL | 模型把“待确认”误解为可先省略 | 明确日期缺失时在校验前终止，保留字段和码值证据但不生成 SQL |
| DELETE、写回、DDL 等边界回答不稳定 | 只依赖提示词约束 | 对执行 SQL、写回资产、DDL/存储过程/调度任务增加确定性只读拦截 |
| 拒绝 DELETE 后建议去客户端执行 | 拒绝结论正确但建议突破安全边界 | 改为统一说明不会执行，也不会提供绕过只读边界的执行建议 |
| SQL 校验对多行、多语句、未限定字段、别名、CTE 和内联子查询存在漏校验或误判 | 首版只用正则校验限定字段，未维护查询块与派生字段作用域 | 保留完整 SQL，并按查询块、物理来源、CTE/子查询输出、投影别名和自连接作用域校验 |
| 多轮会话复用旧开发上下文、关系或候选资产 | 工作流判断扫描整段消息历史 | 工具门禁按最后一条用户消息后的当前轮状态判断，避免跨轮污染 |
| 同一轮切换指标后仍可能沿用旧柜员证据 | 缺失日期拦截扫描了本轮全部开发上下文 | 只使用本轮最后一次 `build_indicator_context` 判断专属字段和码值证据 |
| 越权系统的空结果被解释为资产不存在 | 模型不知道工具结果已经按当前系统权限过滤 | 在运行时提示中明确允许访问的系统清单，要求说明访问范围且禁止推断资产不存在或未接入 |
| `L_ACCT_LOAN` 精确表名被宽泛关键词搜索遗漏 | 首轮检索没有扫描表层目录，且系统显示名称未映射为资产系统编码 | 增加全权限范围表层目录扫描、精确逻辑/物理表匹配，并把用户系统名称解析为 `client_id` 编码 |
| 分析过程机械重复关键词 | Skill 使用固定搜索次数和工具清单，没有根据证据缺口更新探索路径 | 引入咨询、质询、SQL 开发三种模式和动态 `ExplorationPlan`，按目录、表、字段、码值、关系逐层下钻 |
| 抗注入场景把合法码值查询一并拒绝 | 模型未分离敏感请求与可安全完成的资产查询 | 运行时确定性拒绝敏感配置，同时继续执行明确码表的只读查询 |

## 评测边界

- 确定性断言用于发现回归，不能代替监管业务专家对所有业务口径的最终验收。
- 结果依赖 2026-07-15 本地监管集市数据快照；资产绑定或码值变化后应重新运行。
- 真实模型存在措辞随机性，断言允许事实等价的中文表达，但不会放宽工具调用、安全和证据边界。
